# Monitor release health

## Overview

Release health should be evaluated by connecting flag exposure with product, experiment, and operational signals.

## Useful sources

- FeatBit Dashboard for targeting rules, rollout percentage, variations, and environments.
- FeatBit Rich Webhook for reacting to flag changes and notifying external systems.
- FeatBit Experimentation for experiment results and release decisions.
- Observability and APM tools for errors, latency, throughput, and other guardrails.

## Agent role

The coding agent can summarize the current rollout state, collect relevant FeatBit context, and help compare release exposure with operational signals before the team expands or rolls back.

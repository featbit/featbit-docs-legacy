# Review flag audit history

## Overview

FeatBit audit history helps reviewers understand how a flag has changed over time and whether a code change affects a previous release decision.

## When to review audit history

- A new feature flag is added.
- Code wrapped by an existing feature flag is changed.
- A fallback value changes.
- A feature flag is removed from code.
- A flag is archived or deleted in FeatBit.

## Agent role

The coding agent can use audit history as review context, especially when deciding whether a cleanup pull request is consistent with the flag's rollout, experiment result, or operational history.
